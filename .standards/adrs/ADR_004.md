## 1. Problem Statement
Los monolitos no gobernados derivan en acoplamiento caótico ("Big Ball of Mud") y dependencias circulares, mientras que la adopción temprana de microservicios introduce complejidad operativa desproporcionada (latencia, 2PC/Sagas, infra dispersa).

## 2. Decision Matrix
| Directiva | Regla | Especificación Técnica |
| :--- | :---: | :--- |
| **`MUST`** | `ARC-01` | Cada subdominio anotado como `@ApplicationModule` en la raíz de su paquete. Kernel `shared` declarado `@ApplicationModule(type = OPEN)`. |
| **`MUST`** | `ARC-01` | Frontera pública explícita formalizada mediante `@NamedInterface("application")` en `application/package-info.java`. |
| **`MUST`** | `ARC-02` | Comunicación síncrona intermodular autorizada ÚNICAMENTE a través del paquete `application/` (`SYNC-xx`). |
| **`MUST`** | `ARC-03` | Grafo de dependencias entre módulos estrictamente Acíclico (DAG), verificado automáticamente por Spring Modulith. |
| **`MUST`** | `TST-07` | Las 5 suites de ArchUnit y Modulith deben ejecutarse y pasar en verde en cada build de Gradle (`./gradlew check`). |
| **`NEVER`** | `ARC-02` | Importar paquetes `domain` o `infrastructure` de otro módulo. Violación aborta compilación. |
| **`NEVER`** | `ARC-03` | Dependencias circulares entre módulos (`A -> B -> A`). |

## 3. Canonical Package Topology
```text
src/main/java/<base>/
├── shared/            (@ApplicationModule OPEN — Kernel Técnico Base)
├── ordering/          (@ApplicationModule)
│   ├── application/   (@NamedInterface("application") ── Única API Pública Síncrona)
│   ├── domain/        (Privado / Confinado ── Inexpugnable inter-módulo)
│   └── infrastructure/(Privado / Confinado ── Inexpugnable inter-módulo)
└── billing/           (@ApplicationModule)
    ├── application/   (Consume ordering.application.* exclusivamente)
    ├── domain/        (Privado / Confinado)
    └── infrastructure/(Privado / Confinado)
```

## 4. Trade-Offs & Mitigations
* **Disciplina Estricta de Paquetes:** Cualquier clase mal ubicada detiene el pipeline.
  * *Mitigación:* Los tests de ArchUnit reportan mensajes unívocos con archivo exacto y regla violada.
