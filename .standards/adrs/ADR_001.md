guardians:

## 1. Problem Statement
El uso dual de entidades JPA (`@Entity`) para mutaciones y consultas degrada el rendimiento (consultas N+1, retención en Heap), contamina el dominio con anotaciones relacionales y produce `LazyInitializationException` en capas perimetrales.

## 2. Decision Matrix
| Directiva | Regla | Especificación Técnica |
| :--- | :---: | :--- |
| **`MUST`** | `DOM-01` | `AggregateRoot` en Java 21 puro, sin anotaciones de JPA ni frameworks. |
| **`MUST`** | `OUT-01` | Clases `@Entity` confinadas estrictamente a `postgres/jpa/entity/`. |
| **`MUST`** | `OUT-01` | Mapeo explícito bidireccional Agregado <-> `@Entity` en `postgres/jpa/mapper/`. |
| **`MUST`** | `TRX-02` | Control de concurrencia optimista mediante `version BIGINT NOT NULL DEFAULT 0` (`@Version`). |
| **`MUST`** | `OUT-04` | Consultas (`*QueryPort`) ejecutadas vía `NamedParameterJdbcTemplate` + `RowMapper` directas a DTO inmutable (`*Result`, `PageResult`). |
| **`NEVER`** | `OUT-04` | Instanciar `@Entity` o hidratar `AggregateRoot` en operaciones de lectura (`QRY-xx`). |
| **`NEVER`** | `OUT-03` | Permitir lazy loading o exponer proxies de Hibernate fuera del adaptador JPA. |
| **`ALLOWED`** | `OUT-02` | SQL nativo en Java 21 Text Blocks (`*JdbcQueries`) respaldado por índices de `schema.sql`. |

## 3. Canonical Layout
```text
[Command Flow] ──► postgres/jpa/
                   ├── *PersistenceAdapter (implements *RepositoryPort)
                   ├── *PersistenceMapper (AggregateRoot <-> *Entity)
                   ├── *Entity (@Entity relacional)
                   └── *JpaRepository (ACID, @Version)

[Query Flow]   ──► postgres/jdbc/
                   ├── *JdbcQueryAdapter (implements *QueryPort)
                   ├── *RowMapper<*Result>
                   ├── *JdbcQueries (SQL Text Blocks)
                   └── *JdbcRepository (NamedParameterJdbcTemplate)
```

## 4. Trade-Offs & Mitigations
* **Mantenimiento de Doble Modelo:** Requiere `AggregateRoot`, `@Entity` y `*Result` separados.
  * *Mitigación:* Centralizado en `*PersistenceMapper`, testeado de forma aislada con `@DataJpaTest`.
