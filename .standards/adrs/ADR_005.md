# ADR_005: Consumo Directo de Enums de Estado en Adaptadores Primarios

```yaml

rules: [DOM-01, DOM-03, APP-03, APP-04, INP-01, ARC-02]

```

## 1. Problem Statement
El aislamiento dogmático de Arquitectura Hexagonal que prohíbe todo tipo de dominio en adaptadores web genera proliferación de enums espejo redundantes (`OrderStatusWebDto`), mappers triviales y fragilidad de sincronización ante cambios de estado de negocio.

## 2. Decision Matrix
| Directiva | Regla | Especificación Técnica |
| :--- | :---: | :--- |
| **`MUST`** | `DOM-03` | Enums de máquinas de estados (FSM) confinados estrictamente en `domain/model/enums/`. |
| **`MUST`** | `DOM-01` | Enums 100% Java puro, sin anotaciones de Spring, Jackson, JPA ni dependencias externas. |
| **`ALLOWED`** | `APP-03`, `APP-04` | Comandos (`WEB_EXCLUSIVE`), Queries y Results de canal `REST` local pueden utilizar directamente `domain.model.enums.*` (prohibido en `INTERNAL_PORT` inter-módulo por `ARC-02`). |
| **`ALLOWED`** | `INP-01` | Controladores y DTOs web (`*HttpRequest`, `*Response`) pueden importar y utilizar directamente `domain.model.enums.*`. |
| **`NEVER`** | `INP-01` | Adaptadores web dependiendo de ninguna otra clase de `domain.model.*` (Agregados, Entidades o VOs). |

## 3. Canonical Architecture
```text
src/main/java/.../<module>/
├── domain/model/enums/
│   └── OrderStatus.java ─────────────┐
│       (PENDING, CONFIRMED, ...)     │ CONSUMO DIRECTO AUTORIZADO
│                                     ▼
└── infrastructure/adapter/in/web/
    ├── OrderController.java          │ (Sin enums espejos ni mappers redundantes)
    └── dto/OrderResponse.java (usa OrderStatus)
```

## 4. Trade-Offs & Mitigations
* **Acoplamiento Contrato Web-Dominio:** Alterar un estado en el dominio impacta el contrato web.
  * *Mitigación:* Los estados de una FSM son parte del contrato público formal aprobado en `DOMAIN.md` y `API.md`.
